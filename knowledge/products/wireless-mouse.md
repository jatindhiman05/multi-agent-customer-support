# VoltNest Wireless Mouse

SKU: VN-MOUSE-001

The VoltNest Wireless Mouse is an ergonomic wireless pointing device.

## Connection

Connect the mouse using the wireless connection method supplied with the product.

Ensure that the mouse is powered on before attempting to use it.

## Mouse is not responding

If the mouse does not respond:

1. Confirm that the mouse is powered on.
2. Confirm that its wireless connection is available to the computer.
3. Disconnect and reconnect the supplied wireless connection when applicable.
4. Restart the mouse.
5. Try another compatible connection port when applicable.
6. Restart the computer if the problem continues.

If possible, test the mouse with another compatible computer.

If the mouse remains unavailable, contact VoltNest Support.

## Pointer movement problems

If pointer movement is inconsistent:

1. Use the mouse on a clean, stable surface.
2. Check the sensor area for visible dirt or obstruction.
3. Confirm that the wireless connection is stable.
4. Restart the mouse.

If inconsistent movement continues across multiple suitable surfaces, contact VoltNest Support.

## Buttons are not responding

Test the affected button in more than one application.

Restart the mouse and reconnect it before testing again.

If the button consistently fails across applications, contact VoltNest Support.

## Safety

Stop using the mouse if it appears physically damaged, unusually hot, swollen, or otherwise unsafe.

Contact VoltNest Support for safety-related issues.
