# VoltNest Mechanical Keyboard

SKU: VN-KEYBOARD-001

The VoltNest Mechanical Keyboard is a mechanical keyboard designed for productivity and gaming.

## Connection

Connect the keyboard to a compatible computer using its supplied connection cable.

After connection, the operating system should normally detect the keyboard automatically.

## Initial setup

1. Connect the keyboard securely to the computer.
2. Wait for the operating system to detect the device.
3. Open a text field or other suitable application.
4. Press several keys to verify that input is being detected.

## Keyboard is not detected

If the keyboard is not detected:

1. Disconnect the keyboard and reconnect it securely.
2. Try another compatible USB port on the computer.
3. Restart the computer if the keyboard remains unavailable.
4. Test the keyboard on another compatible computer when possible.

If the keyboard works on another computer, the original computer or its configuration may require further investigation.

If the keyboard is not detected on multiple compatible computers, contact VoltNest Support.

## A key is not responding

If an individual key is not responding:

1. Disconnect and reconnect the keyboard.
2. Test the key in more than one application.
3. Restart the computer.
4. Check whether multiple keys are affected.

Do not disassemble or modify the keyboard as part of standard troubleshooting.

Contact VoltNest Support if the key remains unresponsive.

## Safety

Stop using the keyboard if the cable, connector, enclosure, or another component appears dangerously damaged.

Safety-related issues should be reported to VoltNest Support.
