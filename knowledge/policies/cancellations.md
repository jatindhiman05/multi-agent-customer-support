# Order Cancellation Policy

Customers may request cancellation of an eligible order before it has progressed too far through fulfillment.

## Eligible orders

Orders that have not yet shipped may be eligible for cancellation.

Cancellation eligibility must be determined using the current order status.

## Shipped orders

An order that has already shipped cannot be cancelled through the standard cancellation process.

After delivery, the customer may be able to request a return if the order meets the VoltNest Returns Policy.

## Confirmation

VoltNest requires customer confirmation before executing a cancellation.

Asking whether an order can be cancelled does not itself cancel the order.

## Refunds after cancellation

If an eligible cancelled order has a captured refundable payment, VoltNest will process the applicable refund.

If no refundable payment was captured, cancellation may complete without a refund.

## Specific orders

Cancellation eligibility cannot be determined from this policy document alone.

VoltNest Support must check the customer's live order information before confirming whether a particular order can be cancelled.
